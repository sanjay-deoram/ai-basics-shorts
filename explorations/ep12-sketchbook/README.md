# ep12 sketchbook (rejected direction, 2026-10-18)

The first take on ep12 (zero / one / few-shot): a hand-drawn sketch-pad look (rough.js strokes, hand fonts, sticky
notes). v1 had a camera/polaroid metaphor; v2 swapped it for sticky notes and put the code in an IDE window. The user
decided against the whiteboard style ("not a fan") and asked for a style built for developers instead; ep12 was
rebuilt in place as a live IDE + terminal video. Kept here for reference: the scene compositions, the sketch kit
(`sketch.css`, `sketch.js`, needs `rough.js` and the hand fonts from the episode's assets), the storyboard and the v2
render. These files don't run on their own.
