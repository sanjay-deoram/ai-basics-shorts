Choice 3

HyperFrames or Remotion

Both turn code into an MP4 by recording a web page in a headless Chrome browser and stitching the frames with FFmpeg. The difference is what you write.

HyperFrames (HeyGen)Remotion
You writePlain HTML and CSS, with GSAP or CSS for animationReact components
From these design pagesThey carry over almost as they are, since they're already HTML and CSSEach piece gets rewritten as a React component
SetupNo build step. npx hyperframes init, preview, renderA React project with a bundler
Working with ClaudeOfficial Claude Code plugin with a set of video skills, including audio mixingClaude writes React well, but there's more project code to manage
21st.dev componentsTheir look can be rebuilt in HTML and CSSReact and Tailwind, so many drop in directly
Render speedSlower locally. Roughly 3 minutes for 30 seconds of 1080pFaster, and Remotion Lambda renders in the cloud in parallel
MaturityNewer, open-sourced in 2026, used in production at HeyGenYears older, large community, many examples
LicenseApache 2.0, free for any useFree for individuals and very small companies. Larger companies need a paid license
Recommendation

Go with HyperFrames. Your design will be plain HTML and CSS, so every scene can reuse the same files with no rewrite, and Claude is very reliable at writing HTML. One-minute shorts render in a few minutes on your own machine, so cloud rendering isn't needed yet. Remotion is the better choice only if you plan to lean heavily on React components from 21st.dev.

Your machine already has Node 24, which meets the requirement. FFmpeg still needs to be installed.

Sources: HyperFrames on GitHub · Voyager comparison · Cookies for AI comparison · Remotion license

Feedback

How to ask for edits

Every part of every page has a short ID. Point at the ID and say what to change.

1. Turn on edit tags

Tick "Show edit tags" at the top of any page. Every block gets a dashed outline and a label like B-07 or V2-F03.

2. Send the ID and the change

One line per change. Group as many as you like in one message.

C-04 make the dragon's whiskers longer A-12 slow the zoom down a bit V1-F06 tags fly in one at a time B try a teal accent instead of amber

3. Or comment on the page

On the published link you can leave a comment directly on any spot and send it to Claude. Mention the ID in the comment when you can, so the change is easy to find.

After you pick

What happens next

  1. Write DESIGN.md

    Colors, type, mascot rules, motion moves with exact timings and easing, sound pairings, caption style, and the 9:16 safe areas. Every video follows it.

  2. Set up the video project

    Install FFmpeg and the chosen tool, then turn the components into reusable scene blocks: title card, prompt card, before and after split, verdict stamp, end card.

  3. Build episode 01

    The prompting video from the storyboard you picked, rendered at 1080 by 1920, 60 seconds max, with sound effects.

  4. Make it a template

    A short episode script format, so each new topic is mostly writing, and the look stays the same from video to video.
